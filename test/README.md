# 测试

无头测试，只依赖 `jsdom`。在本目录下：

```bash
npm install          # 安装 jsdom
npm test             # 跑两个测试
```

- `smoke.test.js` — 启动、筛选、中英切换、图鉴分页、详情与外链、账号、收藏、
  实拍照片、导入导出、分享编解码与只读守卫、统计、SVG 渲染
- `cloud.test.js` — 注入假 Supabase，验证多设备合并、删除墓碑、批量分批推送，
  以及最关键的一条：**云端挂掉时本地必须照常工作**
- `map.test.js` — 注入 Leaflet 桩，跑真实的地图代码路径：图钉分组、聚合着色、
  popup 内容、批量加入、增量更新（不重建整层、不销毁 popup）、定位、语言切换

三个脚本都不改动仓库文件，失败时以非零码退出。共 191 项检查。

## 变异验证

这套测试用变异测试验证过有效性：把仓库复制一份，逐个注入下列缺陷，
确认每一个都会让测试变红（不是"跑过了"而已）——

类型/系列筛选失效、登录不校验密码、照片不校验 data URI、`Photos.get()`
不校验已落库的值、导入不校验文件来源、只读模式可改他人收藏、
分享链接不校验数据集指纹、地图图钉状态不更新、地图退回逐个 addLayer、
收藏后丢失已加载分页、英文词典缺键。

另有插画层的回归项：SVG 占位符残留、图案配色对比度不足（数据里 26% 的
配色主色是白或极浅色）、图案种类退化、标志性城市退回通用图形。
